# 5 Nights at Deepwatch

Night-guard camera game set in an aquarium.

## Main game (browser)

Play this version:

1. Open `index.html` in a browser, **or** serve the folder and open it (needed for GitHub Pages / local preview).
2. Click the canvas → **New Game**.

Core files:

- `index.html` — page shell
- `game.js` — the game
- `style.css` — page look
- `images/` — room pictures

## Deprecated

`game.py` (pygame) is an **old learning prototype**. Do not add new features there. Use the browser game instead.

`make_placeholders.py` is only for making simple room pictures if you need them.
